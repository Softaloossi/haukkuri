# Haukkuri - Haukkuträkkeri

## Privacy Policy

Privacy policy for **Haukkuri - Haukkuträkkeri**, an Android app for hunting-dog
GPS tracking and peer-to-peer group location sharing.

## About the app

Haukkuri is privacy-friendly by design: no accounts, no ads, no analytics, and
no servers operated by us. Location is shared **directly peer-to-peer** with the
group members you choose; microphone (bark detection) and camera (QR scanning)
are processed **on-device only**. See the policy for full details.

- **Package:** `com.softaloossi.haukkuri`
- **Provider:** Softaloossi
- **Contact:** rami.ojala@softaloossi.fi

## This repository

This repo exists only to host the app's privacy policy as a public web page
so it can be linked from the Google Play listing.
